# Platypus

A high-performance [Next.js](https://nextjs.org) application bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) and optimized for deployment on Cloudflare Workers using [OpenNext](https://opennext.js.org/cloudflare).

---

## Getting Started

### Prerequisites
Make sure you have a modern package manager installed. This project uses Bun by default, but npm, yarn, or pnpm are fully supported.

### Installation
Clone the repository and install dependencies:

```bash
# Using Bun (Recommended)
bun install

# Using npm / yarn / pnpm
npm install # or yarn install / pnpm install
